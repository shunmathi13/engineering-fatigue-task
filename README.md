# Fatigue Life Analysis of a Notched Mechanical Component

This project contains a computational mechanical-engineering task for
assessing the fatigue behaviour and service life of a notched component
subjected to cyclic loading.

The task evaluates material properties, cyclic loading conditions,
component geometry, stress concentration effects, and fatigue behaviour.
The project includes a reproducible execution environment, reference
solution, deterministic verification tests, and validation results.

## Project Structure

- `instruction.md` - Engineering task given to the agent
- `task.toml` - Task metadata and configuration
- `environment/` - Docker environment and input data
- `solution/` - Reference solution
- `tests/` - Deterministic verification tests
- `VALIDATION.md` - Oracle and NOP validation results

## Objective

The objective is to estimate the fatigue life of the specified notched
mechanical component and produce reproducible engineering results from
the supplied input data.
